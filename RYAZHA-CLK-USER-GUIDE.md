# Ryazha-clk — лёгкая инструкция по кнопкам и меню

Короткая памятка **для пользователя**. Технические сведения, состав пакета и актуальная версия указаны в [README.md](README.md) и исходном репозитории [RCU](https://github.com/Ryazhenka-Makers/RCU).

---

## Общие правила (оверлей Tesla)

| Действие | Обычно |
|----------|--------|
| **Стик / крестовина** | Перемещение по списку |
| **A** | Открыть пункт, подтвердить выбор, включить переключатель |
| **B** | Назад (закрыть подменю или экран выбора) |
| **Касание** | Если поддерживается темой — как навигация по списку |

Дальше — что именно делает **каждая кнопка** внутри ryazha-clk.

---

## Главный экран (список: профиль, настройки…)

| Кнопка | Действие |
|--------|----------|
| **A** на **Профиль приложения** | Частоты для **текущей запущенной игры** |
| **A** на **Глобальный профиль** | Частоты **по умолчанию** для всех игр |
| **A** на **Temporary Overrides** | Временные частоты (до сброса), не пишутся в профиль как постоянные |
| **A** на **Настройки** | Общие опции: губернатор, безопасность, экран, экспериментальные |
| **X** | Скрытое меню **Ryazha-Авто** (авторазгон по FPS) |
| **Y** | **Глобальный хоткей** (работает на экранах со списком: главный, настройки, профиль и т.д.): принудительно выставляет **60 Гц** для экрана и связанного лимита — «аварийно вернуть 60». *Внимание:* если в этот момент у вас выбрана строка, где **Y** означает «сбросить частоту» (см. ниже), могут выполниться **оба** действия — сначала обработка строки, затем этот сброс. |

Вверху экрана — **инфопанель**: ID игры, профиль, CPU/GPU/RAM, температуры, питание, FPS (если есть SaltyNX) и т.д. (только просмотр).

## Профиль приложения / глобальный профиль

Одинаковая логика: сохраняются **частоты по режимам** (портатив / док / зарядка и т.д., как показывает заголовок секции).

| Кнопка | Действие |
|--------|----------|
| **A** на **ЦП / ГП / ОЗУ** | Список допустимых частот; сверху часто есть пункт **«по умолчанию» (0)** — как в стоке для этого места |
| **Y** на той же строке (ЦП / ГП / ОЗУ) | **Сбросить** частоту этого модуля в профиле на **значение по умолчанию** (параллельно может отработать глобальный сброс экрана на 60 Гц — см. главный экран) |
| **A** на строках с **числом / ползунком** (экран, губернатор и др.) | Открыть выбор значения или подменю |
| **Губернатор** (стрелка →) | Подменю: ползунки **ЦП**, **ГП**, **VRR** (если включена перезапись частоты экрана в настройках): *не трогать / выкл / вкл / авто* для VRR |

Трекбары (полоски с шагами): двигаете шаг — значение уходит в сисмодуль сразу.

## Temporary Overrides (временные переопределения)

| Кнопка | Действие |
|--------|----------|
| **A** на модуле (ЦП, ГП…) | Выбор частоты из списка или числового диапазона |
| **Y** на строке модуля | **Сбросить** override (снова действуют профиль и глобальные правила); глобальный хоткей 60 Гц может тоже сработать |
| Подменю **Губернатор** | Как в профиле: упакованные режимы CPU/GPU/VRR |

Назначение: быстро проверить частоту «здесь и сейчас», не портя сохранённый профиль.

## Настройки

Вход: главный экран → **A** на **Настройки**.

| Элемент | Как пользоваться |
|---------|-------------------|
| **Губернатор** → | Подменю: минимальная частота губернатора CPU и др. (**A** по пунктам) |
| **Безопасность** → | Лимиты TDP, термотроттлинг, пороги (**A** открывает числа, переключатели — **A**) |
| **Экран** → | Перезапись Hz, напряжение, макс. Гц портатива (ползунок/кнопки). Есть предупреждения о риске для матрицы |
| **Экспериментальные** | Появляется только если включён переключатель **«экспериментальные настройки»** — ток заряда, опрос, UV и т.д. **Осторожно** |

**Оранжевый цвет** текста пункта — настройка связана с **KIP** (после смены может понадобиться сохранение настроек KIP в вашем рабочем процессе, как в основном README).

Переключатели (**Вкл/Выкл**): наведитесь и нажмите **A**, чтобы переключить.

Кнопки с числом справа: **A** → экран **ValueChoice** (список шагов или именованных значений) → **A** на нужном → **B** назад.

## Экран выбора частоты (FreqChoice)

| Кнопка | Действие |
|--------|----------|
| **A** на строке с МГц | Применить эту частоту и вернуться назад |
| **B** | Выйти без смены (если ещё не подтвердили) |

Слева — частота, справа могут быть подписи (UV и т.д.). Цвет строки: белый / оранжевый / красный — уровень «нагрузки» на безопасность по порогам.

---

## Экран выбора числа (ValueChoice)

| Кнопка | Действие |
|--------|----------|
| **A** | Выбрать значение и выйти назад |
| **B** | Назад без выбора |

Часто первая строка — **«По умолчанию»** (0), если это предусмотрено для параметра.

---

## Ошибка (Fatal)

Экран с текстом ошибки: **A** или **B** — закрыть.

---

## Ryazha-Авто (кнопка **X** на главном экране)

| Кнопка | Действие |
|--------|----------|
| Открыть | С главного списка ryazha-clk нажать **X** |
| **A** на переключателе | Включить/выключить авторазгон |
| **A** на параметре с числом справа | Цель FPS, агрессивность, лимиты °C, порог TDP |
| Строки **VRR Авто** и **RAM** | Только подсказки (не кликаются как настройки) |

Минимальные **ЦП/ГП** в авто зависят от выбранного **целевого FPS**: при **30** — нижний пол типичный для лёгкого режима; при **45**, **60** или **60+** — выше (см. **README.md**). Так авто не держит слишком низкие частоты при высокой цели.

**Важно:** авторазгон реально работает только при **валидном FPS** от **SaltyNX**. Без этого режим не подменяет частоты.

## Кратко «куда нажать»

| Хочу… | Куда |
|-------|------|
| Поменять частоты для этой игры | Главный экран → **Профиль приложения** |
| Поменять частоты «для всех» | **Глобальный профиль** |
| Временно, без сохранения в профиль | **Temporary Overrides** |
| TDP, термо, экран, губернатор | **Настройки** и подменю со стрелкой |
| Авторазгон по FPS | Главный экран → **X** |
| Быстро вернуть экран к 60 Гц | Почти любой экран со списком → **Y** (см. примечание про двойное действие выше) |
| Сбросить одну строку частот в профиле | В профиле: **Y** на строке ЦП/ГП/ОЗУ |
| Сбросить override | В Overrides: **Y** на строке |
