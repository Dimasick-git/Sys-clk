# Sys‑clk (форк от Dimasick‑git)

**Кастомная версия модуля управления частотами для Nintendo Switch** с русской локализацией. Основана на проекте RetroNX, сохраняет безопасные лимиты частот.

## Ключевые особенности

- Полная русская локализация интерфейса и документации.
- «Умный разгон» (в стадии тестирования) — автоматическая оптимизация частот под нагрузку.
- Поддержка кастомных тем оформления.
- Виброотклик при изменении параметров.
- Звуковые эффекты для ключевых действий.
- **Безопасные лимиты частот** (согласно рекомендациям RetroNX):
  - CPU: до **1785 МГц** (стандартный максимум);
  - GPU: до **768 МГц** (док‑станция) / **460 МГц** (портатив);
  - RAM: до **1600 МГц** (универсальный лимит).

> *Примечание:* значения 2703 МГц (CPU), 1536 МГц (GPU) и 3200 МГц (RAM) — **теоретический максимум** для консолей. Их использование **не рекомендуется** из‑за риска перегрева и нестабильности.


## Совместимость

- **Прошивка**: Ryazhenka (https://github.com/Dimasick-git/Ryzhenka).
- **Оверлей‑менеджер**: Ryazhahand Overlay ≥ 1.2.3 (https://github.com/Dimasick-git/Ryazhahand-Overlay/releases).
- **Минимальная версия FW**: 5.0.0.


## Установка


1. Скачайте последний релиз из раздела **Releases** на GitHub.
2. Распакуйте архив в корень SD‑карты.
3. Убедитесь, что установлены:
   - Ryazhahand Overlay;
   - актуальная версия Atmosphère.
4. Перезагрузите консоль.

## Настройка


Основные параметры задаются в файле:  
`sdmc:/config/sys-clk/config.ini`


### Примеры конфигураций

**Для игры (по ID):**
```ini
[01007EF00011E000]  # ID игры
docked_cpu=1785       # CPU в док-станции (макс. безопасный)
handheld_cpu=1489    # CPU в портативе (рекомендуемый)
gpu=768             # GPU в док-станции
handheld_gpu=460    # GPU в портативе
mem=1600            # RAM (универсальный лимит)
```

**Глобальные настройки:**
```ini
[global]
default_cpu=1489
default_gpu=460
default_mem=1600
```

## Режимы работы

1. **Авто** — умный разгон (экспериментальный):  
   - анализирует нагрузку;
   - динамически меняет частоты в безопасных пределах;
   - минимизирует перегрев.

2. **Ручной** — фиксированные значения для:
   - док‑станции;
   - портативного режима;
   - зарядки.

3. **Энергосбережение** — сниженные частоты для увеличения времени работы.


## Интерфейс управления


Доступ через:
- **sys‑clk‑overlay** (в Ryazhahand Overlay);
- **sys‑clk‑manager** (через hbmenu).


**Возможности интерфейса:**
- Мгновенное изменение частот (в пределах лимитов RetroNX).
- Мониторинг температур.
- Логирование параметров в CSV.
- Переключение профилей одним нажатием.

## Рекомендуемые лимиты (на основе данных RetroNX)


| Режим | CPU | GPU | RAM |
|------|---------|---------|-------|
| **Док‑станция** | до 1785 МГц | до 768 МГц | 1600 МГц |
| **Портатив** | до 1489 МГц | до 460 МГц | 1600 МГц |
| **Зарядка** | до 1785 МГц | до 768 МГц | 1600 МГц |


> *Важно:* эти значения обеспечивают баланс производительности и стабильности. Превышение лимитов может привести к перегреву.


## Устранение неполадок


**Проблема**: частоты не меняются  
**Решение**:  
1. Проверьте версию Ryazhahand Overlay.
2. Убедитесь, что `sys-clk` активен в Atmosphère.
3. Перезагрузите консоль.


**Проблема**: перегрев при разгоне  
**Решение**:  
1. Снизите частоты до рекомендованных значений (см. таблицу выше).
2. Включите мониторинг температур.
3. Используйте охлаждающую подставку.


## FAQ


**Q**: Работает ли умный разгон на всех играх?  
**A**: В стадии тестирования. Рекомендуется проверять на конкретных тайтлах, соблюдая лимиты RetroNX.


**Q**: Можно ли использовать без Ryazhahand?  
**A**: Да, но интерфейс управления будет доступен только через hbmenu.


**Q**: Сохраняются ли настройки после перезагрузки?  
**A**: Да, все параметры хранятся в `config.ini`.
