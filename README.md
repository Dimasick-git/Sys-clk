## Что такое Ryazha-clk

**Ryazha-clk** — русскоязычная система управления производительностью для Nintendo Switch **Mariko** под Atmosphère. Это не просто набор частот: в одном SD-ready пакете собраны sysmodule, оверлей, KIP-компонент, профили, мониторинг, защита по температуре и питанию, а также автоматический режим **Ryazha-Авто**.

Пакет рассчитан на понятный повседневный сценарий: для каждой игры можно создать свой профиль, быстро проверить значения через временные overrides и при необходимости включить автоматическую подстройку по FPS. Архив готов к распаковке в корень SD-карты — без ручного раскладывания файлов.

> **Важно.** Настройки частот, TDP, напряжения, экрана и памяти могут привести к нестабильности или потере данных. Перед экспериментами создайте резервные копии NAND, PRODINFO, emuMMC и SD-карты. Все изменения выполняются на ваш риск.

## Главное в v3.0.0

| Возможность | Что даёт |
|---|---|
| **Ryazha-Авто** | Автоматически подстраивает производительность под целевой FPS, температуру и доступный запас TDP. Открывается кнопкой **X** на главном экране. |
| **Умные цепочки FPS** | При просадке FPS частоты повышаются последовательностью шагов; при избытке производительности — снижаются. Температура и TDP ограничивают изменения отдельными безопасными шагами. |
| **Профили для игр** | Отдельные CPU, GPU, RAM, Governor, экранные и совместимые дополнительные параметры для текущей игры либо для всех игр. |
| **Temporary Overrides** | Быстрая проверка настроек «здесь и сейчас» без записи в постоянный профиль. |
| **Защита** | Настройки TDP, термолимитов и ограничений производительности помогают держать систему в заданных рамках. |
| **Экран и VRR** | Управление совместимыми экранными режимами, частотой обновления и VRR-логикой там, где это поддерживается конфигурацией. |
| **Мониторинг** | Инфопанель с частотами CPU/GPU/RAM, температурой, питанием, активным профилем и FPS при наличии SaltyNX. |
| **Русский интерфейс** | Основные экраны, действия и уведомления адаптированы для использования в Ryazhahand. |

## Ryazha-Авто: как работает

Ryazha-Авто использует **валидный FPS от SaltyNX**. Без SaltyNX режим не подменяет частоты: это специально сделано, чтобы не принимать случайные или отсутствующие данные за реальную игровую нагрузку.

Логика режима учитывает выбранную цель FPS, текущую производительность, температуру и TDP. Для цели **30 FPS** используются более экономичные нижние границы; для целей **45 FPS, 60 FPS и выше** нижний порог производительности поднимается, чтобы игра не оставалась на слишком низких частотах. Минимальная частота GPU в автоматическом режиме — **307 МГц**.

| Ситуация | Реакция Ryazha-Авто |
|---|---|
| FPS стабильно ниже цели | Постепенно повышает производительность по цепочке шагов. |
| FPS выше цели с запасом | Плавно снижает частоты, избегая лишнего нагрева и расхода питания. |
| Достигнут температурный или TDP-лимит | Ограничивает дальнейшее повышение и возвращает режим к безопасному диапазону. |
| Подозрительный FPS-lock игры | Sysmodule обрабатывает состояние для лучшей совместимости с VRR-логикой. |

Для режима **60+** используются панель-зависимые цели: **64 FPS** на Aula и **71 FPS** на других поддерживаемых панелях. Допустимые температурные пределы задаются в диапазоне **30–80°C**, а TDP — в милливаттах.

## Профили, частоты и тестирование

На главном экране доступны три базовых сценария. **Профиль приложения** применяется к текущей игре. **Глобальный профиль** задаёт значения по умолчанию для остальных игр. **Temporary Overrides** позволяют временно выбрать частоты и сразу проверить поведение игры, не меняя постоянную конфигурацию.

Для CPU, GPU и RAM можно выбрать поддерживаемую частоту или вернуть строку в значение по умолчанию. Раздел **Governor** задаёт совместимые режимы управления производительностью. В настройках также доступны ограничения TDP, температура, экранные параметры и, при включении экспериментального режима, дополнительные опции. Не включайте экспериментальные параметры без понимания их назначения.

## Установка

1. Скачайте [**`Ryazha-clk.zip`**](https://github.com/Dimasick-git/Sys-clk/releases/latest/download/Ryazha-clk.zip) из последнего release.
2. Распакуйте архив **в корень SD-карты** и разрешите объединение папок `atmosphere`, `config` и `switch`.
3. Полностью выключите и заново запустите консоль.
4. Откройте `ryazha-clk.ovl` через Ryazhahand либо Tesla-совместимый менеджер оверлеев.
5. Если нужен Ryazha-Авто, отдельно установите и настройте **SaltyNX**, затем убедитесь, что в инфопанели появился валидный FPS.

> Не распаковывайте ZIP в отдельную вложенную папку. Структура архива уже подготовлена для SD-карты.

### Состав SD-ready пакета

| Путь в архиве | Назначение |
|---|---|
| `atmosphere/kips/rcu.kip` | Загрузочный KIP-компонент. |
| `atmosphere/contents/00FF0000636C6BFF/exefs.nsp` | Sysmodule Ryazha-clk. |
| `atmosphere/contents/00FF0000636C6BFF/flags/boot2.flag` | Ранний запуск sysmodule. |
| `switch/.overlays/ryazha-clk.ovl` | Оверлей Ryazha-clk. |
| `config/ryazha-clk/` | Шаблон конфигурации и языковые файлы. |
| `config/ryazhahand/assets/notifications/rcu.rgba` | Ресурс уведомлений Ryazhahand. |
| `README.md` | Краткая инструкция внутри архива. |

## Быстрый старт

| Что нужно сделать | Куда нажать |
|---|---|
| Настроить игру | Главный экран → **Профиль приложения**. |
| Настроить значения для всех игр | Главный экран → **Глобальный профиль**. |
| Проверить частоты без сохранения | Главный экран → **Temporary Overrides**. |
| Включить автоматическую настройку по FPS | Главный экран → **X** → Ryazha-Авто. |
| Настроить TDP и температуру | **Настройки** → **Безопасность**. |
| Настроить частоту экрана и совместимые VRR-параметры | **Настройки** → **Экран**. |
| Вернуть отдельную частоту к стоку | Наведитесь на CPU/GPU/RAM в профиле и нажмите **Y**. |
| Быстро вернуть экран к 60 Гц | На экране со списком нажмите **Y**. |

Подробные действия по **каждой кнопке**, меню, значениям, зависимостям и ограничениям описаны в [полном пользовательском гайде](RYAZHA-CLK-USER-GUIDE.md).

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Оверлей не открывается | Полностью перезагрузите консоль и проверьте, что ZIP распакован в корень SD-карты. |
| Ryazha-Авто ничего не меняет | Убедитесь, что SaltyNX установлен, FPS валиден и авторазгон включён через **X**. |
| Игра стала нестабильной | Верните CPU/GPU/RAM в значение по умолчанию, отключите temporary override и уменьшите агрессивные параметры. |
| После обновления настройки ведут себя неожиданно | Проверьте активный профиль игры, затем перезапустите консоль. |
| Нужна помощь | Откройте [Issue](https://github.com/Dimasick-git/Sys-clk/issues) и приложите модель консоли, версию Atmosphère, версию Ryazha-clk и описание действий до ошибки. |

## Обновления

Новые версии публикуются на странице [Releases](https://github.com/Dimasick-git/Sys-clk/releases). Установка обновления выполняется тем же способом: распакуйте новый `Ryazha-clk.zip` в корень SD-карты с объединением папок и перезагрузите консоль.

Обычные внутренние изменения не перезаписывают уже опубликованный release. Если выпущена новая версия, она получает отдельный тег и отдельный архив; исправление уже опубликованного asset допускается только отдельной контролируемой процедурой.
